## Summary

standalone inline-recipe fixture below, but `c2j test validate` executes the same
inline graph and then reports the case as `invalid` with no actionable
diagnostic.

This report is self-contained. It does not require access to the C2 recipes
repository, local `/src` files, or any other project assets.
