This site is the maintained reference for authoring c2 recipes with `c2j`.
It replaces the older `guides/` pile with a Hugo Markdown site organized by task:
learn the concepts, author recipes, choose ops, test workflows, and reuse proven patterns.

The reference is example-first. Complete examples live under `docs/examples/` and are validated with current `c2j` commands. Use the examples as the source files to copy from; page snippets are explanatory.
